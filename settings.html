Settings

All settings are optional, you can use Sqlime without them.

Changes are only stored after clicking “Save settings”.

GitHub credentials (to enable sharing)

This is not your GitHub password. Create an API token with a 'gist' scope in the GitHub settings. The token alone is enough for sharing. In Firefox Private Browsing the stored token is removed when the private session ends.


OpenAI credentials (to enable 'Ask AI')

Create an API key in the OpenAI account. In Firefox Private Browsing the stored key is removed when the private session ends.
